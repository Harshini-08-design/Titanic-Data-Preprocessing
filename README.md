# Titanic Data Preprocessing Project

This project demonstrates basic data preprocessing techniques using the Titanic dataset in Python.

## Tasks Completed
- Loaded and explored the dataset
- Checked dataset information and statistics
- Handled missing values
- Median imputation for Age column
- Mode imputation for Embarked column
- Dropped Cabin column due to excessive missing values
- Applied Label Encoding on Sex column
- Applied One-Hot Encoding on Embarked column
- Visualized Age distribution using Histogram
- Exported cleaned dataset as CSV

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Files Included
- Titanic-Dataset.csv
- cleaned_titanic.csv
- Titanic_Preprocessing.ipynb (Assessment-1.ipynb)
